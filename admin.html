Winner drawing

How the drawing stays auditable

  1. Publish a commitment before entries close. The server generates a secret seed and publishes only its SHA-256 hash on the public site.
  2. Announce a public entropy source in advance, such as a specific state lottery result on the drawing date, so no one (including administrators) can predict the outcome.
  3. Close entries (pause sales, reach the end date, or sell out), then enter the public value and draw.
  4. The seed, entropy, eligible ticket list and algorithm are published at /api/drawing so anyone can recompute the result.

Pre-launch checklist

Items marked “auto” update themselves from the campaign settings and server configuration. Tick the others as they are completed; each change is recorded in the activity log. Real payments stay disabled until the approvals are done and a developer switches Stripe to live keys.

Start a new campaign

After the drawing, reuse this site for the next campaign. The current campaign’s complete database (entries, payments, emails, drawing) is archived on the server, then cleared. Branding, restaurants and rules text are kept for you to edit. Entries stay paused until you set new dates.
